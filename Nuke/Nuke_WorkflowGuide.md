# 色彩空间

## 默认色彩空间

Nuke 的色彩空间默认为 sRGB

## 更改为 ACES

- 打开 Preference，找到色彩空间设置选项
- 选择 ACES，并确认应用
- 之后工程的色彩空间即切换为 ACES

## 注意事项

- 一般 JPEG 格式图片的色彩空间为 sRGB
- EXR 格式图片更加清晰保真，使用最广泛，但只能用 Nuke 打开，其他看图软件可能显示不正确

# 工程设置

按 S 键打开工程设置

- 在 Format 处设置工程尺寸

# 节点

## Read 节点

- 按 R 键导入素材，连接 Viewer 节点即可显示
- 单击属性中的刷新按钮可重新载入资源

## Write 节点

- W 键添加 Write 节点
- 在属性中指定输出路径
  - 路径命名格式：`名称.####.图片格式`（`####` 代表帧数位数）
  - JPEG 格式没有 Alpha 通道，文件较小
- 输出视频格式一般为 MOV
  - 属性中指定路径时必须带格式后缀
  - 指定色彩空间
  - 指定编码方式，MOV 常用 H.264
  - 最后单击 Render 按钮输出
- Write 节点属性中需单独设置色彩空间
  - 若与上游素材色彩空间不一致，导出图像观感会发生变化
  - 调整色彩空间后再次单击 Render 会覆盖原文件
- 输出质量设置越高，细节越好

## Viewer 节点

- 素材连接 Viewer 节点即可在视窗中显示
- 按 `1`、`2`……切换显示上游对应序号的节点
- 按数字键查看对应 Viewer 节点输入端的图像
- 点亮渲染窗口上方的固定按钮，移动画布也不会中断渲染

## Merge 节点

- 合成两张图片为一张，一般用于背景与物体的合成
- B 输入端为主图层（背景），A 输入端为辅助图层，mask 为辅助图层的遮罩
  - 合成过程：A 图层 × mask 后与 B 图层进行合并
- 分层合成时，有 matte 的情况下，merge 模式选择 matte
- Merge 节点的混合强度参数控制合并的强度
- 合并带有 Glow 效果的对象时，merge 模式选为 screen 或 plus
  - screen/plus 模式：黑色区域透明，亮色区域更亮

## Grade 节点

- 用于调节图层亮度和颜色
  - gain 值和 gamma 值都可以调节图层亮度
  - gain 值控制亮度
  - 单击右侧调色盘可调整颜色
- 生成距离黑白遮罩
  - 上游接 Shuffle 节点读取的 depth.z 通道
  - 相当于 fit 函数，将上游的距离值映射为 0 到 1
    - 距离相机近的区域趋于黑色，距离远的趋于白色
  - 勾选 clamp 后，小于 blackpoint 的值变为 0，大于 whitepoint 的值变为 1
- channel 设置为 alpha 通道可对上游图层的透明通道单独调整
  - 调整 gamma 值和 blackpoint 值可以减小边界的半透明程度（消除白边）
- Grade 节点的 blackpoint/whitepoint 相当于 Houdini 中的 fit 函数

## Shuffle 节点

- 用于读取图片的特定通道（如 Z 通道）
- 可将输入端图层的对应通道提取到输出端图层的对应通道
  - 例如将输入端图层的 depth.z 通道提取到输出端图层的 rgba 通道
- Shuffle 节点读取深度通道后，后接 Grade 节点可将距离值可视化为黑白图

## Constant 节点

- 新建纯色背景
- 注意尺寸（Format）需与图片一致
- 可在属性中调整背景颜色
- 将导入的图片与 Constant 节点 merge，可使图片尺寸与主图层一致

## Roto 节点

- 绘制自定义遮罩区域
  - 双击节点进入属性面板
  - 点亮 Viewer 窗口左侧的绘制模式按钮进入绘制模式
  - 在 Viewer 窗口中绘制封闭区域作为遮罩，连接到下游节点的 mask 端
- 自带 K 帧功能
  - 在 K 帧的时间点移动遮罩到对应位置即可 K 帧
  - K 帧成功后时间轴变为蓝色

## Rectangle 节点

- 创建矩形区域
- 可用作遮罩

## Glow 节点

- 为图层添加辉光效果
- 勾选对应选项使得发光效果只保留辉光，对比不勾选更加模糊

## Keyer 节点

- 将上游图层的亮度图转变为黑白值，存储到 Alpha 通道

## Premult 节点

- 将输入端图层的颜色通道（RGB）与 Alpha 通道相乘后输出为新的 RGB 颜色通道

## Saturation 节点

- 调节合成结果的饱和度
- 用于增强颜色的区分度

## Blur 节点

- 模糊图层，实现均匀过渡效果

## Transform 节点

- 对输入端图层进行旋转、移动、缩放
- 取消勾选自动填充选项可关闭自动补边

## Noise 节点

- 生成黑白噪波纹理，可用作遮罩
  - 例如作为 Grade 节点提高亮度的遮罩，产生云雾效果
- 参数
  - 缩放控制纹理大小
  - 偏移控制纹理位置
  - 叠加次数控制纹理细节层次

## 3D 节点

ABC 模型（相机和模型）可直接导入 Nuke

- 将模型按数字键显示，Viewer 窗口会自动切换到 3D 视图
- 导入的 ABC 节点的 img 输入端可将图片粘贴到模型上
  - 注意导入模型前模型比例需与图片一致，且已展 UV
- 在 3D 模式下可框选模型进行选择
- 3D 模式下按 A 可切换到平面模式

scanlinerender 节点

- 连接相机、模型，以及已经投射图片的模型
- 可查看相机视角下模型上的图片
- 图片尺寸为工程尺寸，无法单独更改
- 随着相机移动，视窗内图片也会随之移动

三维投射法

- 使静止图片随相机移动具有 depth.z 通道效果，成为合成层中的一层图片

# 快捷键

```
r                       //导入素材（添加 Read 节点）
W                       //添加 Write 节点
d                       //关闭或打开当前节点的效果
s                       //打开工程设置
a                       //在 RGB 显示模式与 Alpha 显示模式之间切换（Viewer 窗口内）
1、2、3……               //将节点显示在对应编号的 Viewer 输入端
Ctrl + 左键             //3D 视图旋转视窗
Ctrl + 中键             //3D 视图移动视窗
滚轮                    //3D 视图缩放视窗
Ctrl + 单击线           //在连线上生成中继节点
Ctrl + Shift + 拖动     //将一个 Read 素材替换为另一个 Read 素材
```

# 其他

## 导入素材注意事项

- 视频格式必须为 MOV
- 导入路径不能含有中文
- 导入时需确认色彩空间

## 通道

- depth.z 通道代表该层图像距离相机的距离
- 有 forced matte 的图层，自身和 forced matte 的部分都有 depth.z 通道
- 注意：云等半透明的物体不能使用 depth.z 通道

## 遮罩（mask）

- 带有 mask 连接端的节点，mask 的作用是使节点效果只在 mask 区域生效

## 合成白边问题

- 分图层边缘出现白边的原因是 Alpha 通道半透
- 解决方法：使用 Grade 节点的 channel 设置为 alpha 通道，调整 gamma 值和 blackpoint 值，减小边界半透明程度

## 属性面板

- 双击节点可进入属性面板
- 修改属性面板上方的最大节点数参数，可调整同时显示的最大节点数，不影响最终效果

## 3D 场景规范

- 一般地面的位置为 y=0，相机位置要高于地面
